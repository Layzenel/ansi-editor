# Changelog

## 1.0.0 — 2026-11-05

First release (MVP).

- Text-area button (component patch with DOM fallback), global open hotkey.
- Editor: colors, background, bold, underline, reset, clear, pipette, style indicator.
- Preview, raw code view with text editing, layouts (side by side / tabs / editor only).
- Effects: rainbow and alternate.
- Undo/redo (100 steps, typing coalescing), draft autosave, presets, recent documents.
- Length counter with breakdown, Nitro-aware limit, optimizer.
- Import from message box, clipboard, paste, message context menu; export by insert, send, copy.
- Message context menu: open, edit own message (only the ANSI block changes), copy as ANSI / plain.
- Settings panel, versioned storage with validation, Russian and English UI.
